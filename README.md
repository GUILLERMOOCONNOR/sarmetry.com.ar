# sarmetry.com.ar

Sarmetry — Interferometría y teledetección aplicada. Monitoreo y detección de desplazamientos para minería y Oil & Gas.

Sitio estático (una sola página, `index.html`) publicado con GitHub Pages. Dominio gestionado en NIC Argentina y delegado a Cloudflare.

## Estructura

- `index.html` — página única con secciones ancladas (CSS y JS incluidos)
- `logo.svg` — isologo y favicon
- `og-sarmetry.png` — imagen de vista previa al compartir el link (WhatsApp, redes)
- `CNAME` — dominio personalizado para GitHub Pages
